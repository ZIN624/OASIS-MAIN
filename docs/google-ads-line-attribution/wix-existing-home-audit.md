# OASIS本店｜Wix既存トップからの予約導線・公開ページ調査（2026-10-18）

## この調査で変更したもの
なし。Google広告・Wix・既存LIFF・GA4の公開設定には手を加えず、公開情報を閲覧しただけ。

## 確認済みの導線
- Google広告の「オアシス統括広告」は https://www.cuthome-oasis.com/ を最終URLとして使用。
- Wixトップでは本店の「LINEで予約をする」ボタンが `/本店新規問い合わせ` ページに遷移。
- そのページにLINEの友だち追加に進む「LINEで予約する」ボタンがあり、`line.me` ドメインへ遷移。
- 本店詳細ページ `/本店詳細` にも独立した「LINEで予約する」ボタンがある。
- 現在の予約希望LIFFは `https://zin624.github.io/OASIS-MAIN/`（ユーザーによる動作確認済み）。サイトからLINEを経由しLIFFに到達する実ブラウザの全経路は未検証。

## 確認できた改善候補
1. トップページの「堀町店のみネット予約」表記は、本店の「LINE予約希望フォーム」がある事実との違いを利用者に説明していない。即時予約確定型は堀町店のみといった意図なら、その違いを明示する。
2. トップページ「初めての利用 とメッセージを送る」説明は、フォームから希望日時・メニューを送信する現在の運用と不一致の可能性がある。既存のLINEチャットでの予約相談も残す。
3. 本店詳細ページのカット最終受付は「PM19:00まで」、本店新規問い合わせページでは「PM18:00まで」と記載差がある。店舗確認後、正しい受付時刻に統一。
4. 予約CTAは共通トップから本店問い合わせページを挟みLINEに入る。広告クリックの大半はモバイルのため、実スマホで遷移数と離脱ポイントを測る価値がある。
5. 広告やトップページの「予約する」を「予約希望をLINEで送信する」などに明確化し、送信で予約確定ではないことを記載。

## Wix編集権限取得後の最小修正案
- 新規LPを作らず、既存トップ内の本店予約CTAの視認性を改善。その他店舗・チャットに影響させない。
- 文言案: 「【OASIS本店】LINEで予約希望を送る」「ご希望日時・メニューをフォームから送信いただき、スタッフの返信で予約が確定します。」
- ネット予約案内は「堀町店ではオンライン予約に対応。本店ではLINEの予約希望フォームをご利用いただけます」と機能の違いを説明。実際にどの店舗が即時確定型なのかは店舗側で事前確認。
- 「初めての利用 と送信」文言は、最新のLIFF予約フォーム導線に合わせて整理。LINEチャットで相談できることは維持。
- 営業時間は現場確認後に統一。修正前にどちらを正とするかスタッフと確定。
- GA4タグは既存サイトにあるIDを確認してから対応し、`G-D9P3LB3Q1C`（LIFF側）の誤複製や他店舗のデータ混合を避ける。
